The MainWP Early Access Extension lets you opt in to Early Access updates for MainWP Dashboard and MainWP Child and preview supported MainWP Lab features before they are publicly released. This allows you to test new functionality, provide feedback, and prepare for upcoming changes.

## Key Features

- Opt in to nightly MainWP Dashboard and MainWP Child builds from mainwp.com
- Enable nightly MainWP Child updates globally or per site
- Review what changed in recent nightly builds on the **Nightly Changes** tab
- Roll MainWP Dashboard or MainWP Child back to the latest stable WordPress.org release, or roll add-ons back to their latest stable release
- Preview MainWP Lab features such as Telemetry, MainWP Bridge, MCP with Abilities API, Patchstack Integration, and the new Help Documentation
- Provide early feedback to shape development
- Prepare your workflow for upcoming changes

## Installation

The MainWP Early Access Extension needs to be installed only on your MainWP Dashboard site. You can [install it as any other MainWP add-on](/dashboard/overview/manage-extensions#install-add-ons).

## Getting Started

<Steps>
<Step title="Install and activate the add-on">
Navigate to **MainWP > Add-ons > Manage Add-ons** and install the Early Access Extension.
</Step>
<Step title="Open the Lab page">
Go to **MainWP > Lab** and use the **Early Access Settings** card to open the Early Access settings page.
</Step>
<Step title="Configure update access">
Select **I agree to receive nightly builds** to give nightly consent, and choose whether to **Let WordPress automatic updates install nightly builds**. Then use **Enable Early Access for MainWP Dashboard** and **Enable Early Access for MainWP Child Plugin** to control nightly update checks.
</Step>
<Step title="Manage MainWP Child access per site">
Open a child site's Early Access settings to use **MainWP Child Early Access** with **Use global setting**, **Enable**, or **Disable**.
</Step>
<Step title="Test Lab features">
Use the **Lab** tab to review available feature cards and enable supported options, such as Telemetry.
</Step>
</Steps>

<Warning>
Early Access features may be unstable or incomplete. Use them in testing environments before deploying to production sites.
</Warning>

## Database Health Check

Early Access Extension 5.2.1 supplies its telemetry queue table and expected column definitions to MainWP Dashboard's database schema checks. The Extension uses this table to hold Telemetry events before they are sent. With MainWP Dashboard 6.2 or later and the Extension active, open **MainWP > Info > Server** and review the **Database** section for missing tables, missing columns, or incorrect column definitions.

See [Database Health Check](/dashboard/overview/mainwp-database-health-check) for interpreting the results and preparing a support report. These checks report the Dashboard database structure. They do not repair tables or check Child site databases.
