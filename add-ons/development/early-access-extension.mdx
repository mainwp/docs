The MainWP Early Access Extension lets you opt in to Early Access updates for MainWP Dashboard and MainWP Child and preview supported MainWP Labs features before they are publicly released. This allows you to test new functionality, provide feedback, and prepare for upcoming changes.

## Key Features

- Opt in to nightly MainWP Dashboard and MainWP Child builds from mainwp.com
- Enable nightly MainWP Child updates globally or per site
- Roll MainWP Dashboard or MainWP Child back to the latest stable WordPress.org release
- Receive nightly updates for supported, license-activated Add-ons after nightly consent, and roll them back to their latest stable release
- Review Dashboard, Child, and Add-on build notes on the **Nightly Changes** tab
- Preview MainWP Labs features such as Telemetry, MainWP Bridge, Patchstack Integration, and the new Help Documentation
- Provide early feedback to shape development
- Prepare your workflow for upcoming changes

## Installation

The MainWP Early Access Extension needs to be installed only on your MainWP Dashboard site. You can [install it as any other MainWP add-on](/dashboard/overview/manage-extensions#install-add-ons).

## Getting Started

<Steps>
<Step title="Install and activate the add-on">
Navigate to **MainWP > Add-ons > Manage Add-ons** and install the Early Access Extension.
</Step>
<Step title="Open the Labs page">
Go to **MainWP > Labs** and click **Settings** on the Early Access card to open the Early Access settings page. Click **Nightly Changes** on the same card to review recent builds.
</Step>
<Step title="Configure update access">
In **General Settings**, turn on **Receive nightly builds** to give nightly consent, and choose whether **Automatic installation** lets WordPress install nightly builds. Then use **Enable Early Access for MainWP Dashboard** and **Enable Early Access for MainWP Child Plugin** to control nightly update checks. If you used Early Access before version 6.0, opt in again after updating.
</Step>
<Step title="Manage MainWP Child access per site">
Open a site's dashboard from **MainWP > Sites** and click **Early Access**. Under **MainWP Child Early Access**, select **Use global setting**, **Enable**, or **Disable**.
</Step>
<Step title="Test Labs features">
Use the **Labs** tab to review available feature cards and enable supported options, such as Telemetry.
</Step>
</Steps>

<Warning>
Early Access features may be unstable or incomplete. Use them in testing environments before deploying to production sites.
</Warning>

## Nightly Add-on Updates

With MainWP Dashboard 6.5 or later and Early Access Extension 6.0 or later, you can opt into nightly updates for supported Add-ons with activated licenses. Open the **Early Access** tab to give nightly consent. Review Add-on changelogs on **Nightly Changes** before installing an update.

See [Nightly Add-on Updates and Changelogs](/advanced/miscellaneous/early-access-updater#nightly-add-on-updates-and-changelogs) for consent, installation, changelog columns, and returning to stable releases. Nightly builds do not require a GitHub Personal Access Token.

## Database Health Check

Early Access Extension 5.2.1 supplies its telemetry queue table and expected column definitions to MainWP Dashboard's database schema checks. The Extension uses this table to hold Telemetry events before they are sent. With MainWP Dashboard 6.2 or later and the Extension active, open **MainWP > Info > Server** and review the **Database** section for missing tables, missing columns, or incorrect column definitions.

See [Database Health Check](/dashboard/overview/mainwp-database-health-check) for interpreting the results and preparing a support report. These checks report the Dashboard database structure. They do not repair tables or check Child site databases.
