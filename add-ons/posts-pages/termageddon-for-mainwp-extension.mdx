Termageddon for MainWP is a free Integration Add-on developed by Termageddon. Using this add-on, you can create new policy pages or link existing published pages on your Child Sites and manage them from your MainWP Dashboard. The add-on also checks Termageddon Policy Set statuses so you can see when a linked Policy Set requires action.

## Set Up the Add-on

<Steps>
<Step title="Go to your MainWP Dashboard">
</Step>
<Step title="Go to Add-ons > Manage Add-ons">
</Step>
<Step title="Click the Install Add-ons button">
Click the **Install Add-ons** button.
</Step>
<Step title="Locate Termageddon for MainWP and select it">
</Step>
<Step title="Click the Install button">
</Step>
<Step title="Activate the add-on">
Once the installation process is complete, click the **Activate Add-ons** button.
</Step>
<Step title="Navigate to Add-ons > Termageddon for MainWP">
</Step>
<Step title="Add your Termageddon API key">
Click **Add Termageddon API Key**, enter the API key generated in your [Termageddon Dashboard](https://app.termageddon.com/settings), and click **Save API Key**. After the key is saved, use **Manage Termageddon API Key** to replace or remove it.

![Add Termageddon API Key button in Termageddon for MainWP](/images/add-ons/termageddon-api-key-button.png)
</Step>
</Steps>

## Create or link Termageddon policy pages

<Steps>
<Step title="Login to your MainWP Dashboard">
</Step>
<Step title="Navigate to Add-ons > Termageddon for MainWP">
</Step>
<Step title="Locate the site for which you wish to create a policy page">
</Step>
<Step title="Click the Add Page button in the appropriate column">
Click **Add Page** under **Privacy Policy**, **Terms of Service**, **Disclaimer**, or **Cookie Policy & Consent Tool**.

![Add Page menu with the searchable existing-page selector](/images/add-ons/termageddon-existing-page-selector.png)
</Step>
<Step title="Create a new page or select an existing page">
Choose one of these options:

- **Create new page:** Open the policy page editor, enter the page title, paste the **Termageddon Embed Code**, review the page options, and click **Publish**.
- **Link an existing page:** Select a published page from the menu. Use the search field to find a page by title. Only published pages can be linked.

After an existing page is linked, the table displays **Edit Page** for that policy type.
</Step>
</Steps>

<Info>
When a new policy page is published to multiple sites, the results list reports whether the page was created, updated, or failed for each processed site.
</Info>

## Edit, relink, or unlink a policy page

After you create or link a policy page, **Add Page** becomes **Edit Page**. Open the menu to:

- Select **Edit page** to open the policy page editor.
- Search under **Or Relink To a Page** and select another published page to replace the current mapping.
- Select **Unlink page** to remove the mapping from Termageddon for MainWP. Unlinking does not delete the page from the Child Site.

You can also select **Unlink [policy type]** from the ellipsis menu at the end of the site's row.

## Link a child site to a Policy Set

After you create a Policy Set in the Termageddon Dashboard, you can link a Child Site to it. In the **Policy Set** column:

- Click **Link Existing** to open the Child Site edit screen at **Termageddon Website Policies**. Select a Policy Set from **Link with policy set (optional)**, and click **Save Settings**.
- Click **Create New** to open the Termageddon Dashboard and create a Policy Set.

![Link Existing and Create New buttons in the Policy Set column](/images/add-ons/termageddon-policy-set-actions.png)

The **Policy Status** column displays **Active**, **Update Required**, **Incomplete**, or **Pending Invite** for linked Policy Sets. Sites without a linked Policy Set display **No Policy Set**.

## Filter sites

Use **Filter by status** to show Child Sites with one of these Policy Set statuses:

- Active
- Update Required
- Incomplete
- Pending Invite

![Filter by status menu showing the available Policy Set statuses](/images/add-ons/termageddon-status-filter.png)

Use the table's **Search** field to narrow the displayed rows further.

<Note>
A Child Site must be linked to a Policy Set before Termageddon can report a Policy Status for it.
</Note>
