Installing the Wordfence Integration requires two steps:

- Install and activate the add-on on your MainWP Dashboard site.
- Install and activate Wordfence Security on your child sites.

## Wordfence Settings

### Global Settings

Go to **MainWP > Add-ons > Security > Wordfence**. The integration provides these network-level tabs:

- Wordfence Overview
- Options
- Live Traffic
- Blocking
- Firewall
- Scan
- Diagnostics

Use the settings tabs to define network defaults. Saving a network settings section synchronizes that section to child sites that are not using individual overrides. Sites with **Override general settings** enabled keep their individual settings.

If you install Wordfence Security on additional child sites, sync them and re-save each relevant network settings tab to apply the defaults.

### Settings Added in 5.2

Wordfence Integration 5.2 adds these controls to the existing settings tabs. Configure them globally or from a site's Wordfence settings when individual overrides are enabled, then click **Save Settings**.

| Tab | Setting | Purpose |
|-----|---------|---------|
| Options | **Display "Audit Log" menu item** | Show the Wordfence Audit Log menu item in the Child site's WordPress admin |
| Options | **Trusted Proxy Preset** | Choose **None**, **Amazon CloudFront**, **Ezoic**, or **Quic.cloud** to configure trusted proxy handling |
| Options | **Look up visitor IP locations via Wordfence servers** | Enable Wordfence's remote visitor IP location lookup |
| Scan | **Monitor Web Application Firewall status** | Include the firewall's status in scan checks |
| Scan | **Use only IPv4 to start scans** | Use IPv4 when starting a scan |
| Scan | Scan resume attempts | Set the maximum number of scan resume attempts from `0` through `5` |

<Note>
In Wordfence Integration 5.2.2, the Scan tab's `0`-`5` resume-attempt selector is labeled **Alert me with scan results of this severity level or greater**. That selector controls scan resume attempts.
</Note>

## Wordfence Dashboard

Go to **MainWP > Add-ons > Security > Wordfence** and open the **Wordfence Overview** tab. The sites table shows child sites where Wordfence Security is installed, including plugin status, version, visibility, last scan, and update availability.

- If the plugin is inactive, the **Activate Plugin** action appears in the site row.
- If an update is available, the **Update Plugin** action appears in the site row.

### Available Actions

The row action menu includes **Overview**, **Edit**, **Open Wordfence**, and **Hide Plugin** or **Unhide Plugin**. For active installations, it also includes **Scan Site**, **Live Traffic**, **Blocking**, **Scan Results**, and **Deactivate Plugin**. Inactive installations offer **Activate Plugin**. **Update Plugin** appears when an update is available.

To deactivate Wordfence Security on several sites, select their checkboxes in **Wordfence Overview**, choose **Deactivate** from **Bulk Actions**, and click **Apply**. The integration processes selected active installations. Use **Activate** to enable selected inactive installations again. Deactivation turns off Wordfence Security on those Child sites.

#### Important Notes

If you know that you have the plugin installed on a child site, but the child site doesn't appear in the list, try to re-sync your sites.

## Monitor Child Sites Live Traffic

To monitor live traffic for one child site from your MainWP Dashboard:

- Open the **Wordfence Overview** tab.
- Locate the child site and click **Live Traffic** in its row action menu.
- The integration opens the live traffic view for that site.

![Screenshot of Live Traffic view showing requests to a child site](/images/add-ons/21f0fedceb53.png)

If live traffic is disabled, open the network-level **Live Traffic** tab, set **Enable live traffic logging** to **All Traffic**, and click **Save Settings**. If the site uses individual overrides, configure the same option from the site's **Wordfence > Live traffic** tab instead.
