## Check Sites via WP CLI

If you prefer running SSL checks from the command line, or want to trigger them from a script or cron job outside of the MainWP Dashboard's built-in scheduler, use the WP-CLI commands the extension registers under `wp mainwp-ssl-monitor`.

Both commands accept either a comma-separated list of child site IDs or the `--all` flag to target every child site.

Check the SSL certificate for one or more sites:

```bash
wp mainwp-ssl-monitor check 2
wp mainwp-ssl-monitor check 2,5
```

Check all sites:

```bash
wp mainwp-ssl-monitor check --all
```

View saved SSL certificate information for one or more sites without triggering a new check:

```bash
wp mainwp-ssl-monitor info 2
wp mainwp-ssl-monitor info 2,5
wp mainwp-ssl-monitor info --all
```
