MainWP Cache Control extension allows you to automatically purge the Cache on your child sites after performing an update of WP Core, Theme, or a Plugin through the MainWP Dashboard. Currently supported caching solutions are

- Cloudflare

and the following caching plugins:

- Breeze
- LiteSpeed Cache
- Siteground Optimizer
- Swift Performance Lite and Pro
- WP Fastest Cache
- W3 Total Cache
- WP Rocket
- AccelerateWP
- Hummingbird Performance
- Cache Enabler
- Nitropack
- Autoptimize
- Nginx Helper
- WP Optimize
- Comet Cache
- FlyingPress
- WP Super Cache
- Rocket.net
- Pressable Cache Management
- RunCloud Hub

Overview of when the last automatic Cache purge occurred and what the currently detected Caching solution is for your Child sites can be found in the table located on **MainWP \> Sites \> Manage Sites** page. <img src="/images/add-ons/cache-control-settings.png" alt="Screenshot of Manage Sites table showing Cache Control columns with last purge time and caching solution" />

## Manually clear cache

The cache will be cleared automatically upon WP Core, Theme, or a Plugin update, but you can also manually trigger the clear.

### From the Manage Sites table

Cache can be cleared for any number of sites from the Manage Sites page. Select a number of desired sites, or all of them, and then from the Bulk Actions menu, select Clear Cache Control, and then click **Apply**. <img src="/images/add-ons/cache-control-purge-action.gif" alt="Animated screenshot showing bulk Clear Cache Control action being applied to multiple sites" />

### Using widgets

Cache Control widgets are located on the [Overview](/getting-started/mainwp-user-interface) page and the [Individual Child Sites Overview](/getting-started/mainwp-user-interface) pages. Locate them and simply click the Clear Cache button. If you do not see the widget, you may need to enable it from the [Page Settings](/getting-started/mainwp-user-interface). <img src="/images/add-ons/cache-control-purge-success.png" alt="Screenshot of Cache Control widget with Clear Cache button" />

## Cloudflare cache purging

To purge Cloudflare cache, enable **Purge Cloudflare cache** in the extension settings and provide valid Cloudflare API credentials. <img src="/images/add-ons/cache-control-cloudflare-settings.png" alt="Screenshot of Cloudflare API settings with Email and API Key fields" />

<Note>
  Since version 4.0.1, Cache Control purges both Cloudflare and the supported caching plugin at the same time. Previously, only the caching plugin was purged when both were present.
</Note>

### Choose an authentication method

From version 5.1, you can choose how the extension authenticates with Cloudflare using the **Authentication method** dropdown:

- **API Token** (recommended) — A scoped token created in your Cloudflare dashboard. Use this for least-privilege access; tokens can be limited to the zones and permissions required for purging cache.
- **Email & API key** — Your Cloudflare account email and Global API Key. The Global API Key grants full access to your Cloudflare account, so prefer API Token when possible.

The credential fields shown on the settings page change to match the method you select.

### Credential validation

When you save the settings, the extension makes a lightweight test request to the Cloudflare API to verify your credentials:

- For **API Token**, it calls `GET /user/tokens/verify`.
- For **Email & API key**, it calls `GET /user`.

If validation fails, your settings are still saved, but a yellow notice appears with the error returned by Cloudflare (for example, an invalid token or incorrect email/key). Update the credentials and save again to clear the notice.

Validation is skipped when the credential fields for the selected method are empty.

## Change Cache Control settings on a Single Site

<Steps>
  <Step title="Login to your MainWP Dashboard">
    
  </Step>
  <Step title="Go to the MainWP > Sites > Manage Sites page">
    
  </Step>
  <Step title="Locate the Child site, open its Dashboard and go Cache Control page">
    Locate the Child site, open its Dashboard and go **Cache Control** page

    1. Set **Automatically purge cache** to **Yes**, **No**, or **Use global setting**.
    2. Set **Purge Cloudflare cache** to one of:
       - **Use global setting** — inherit the dashboard-wide Cloudflare configuration.
       - **Yes (use site-specific credentials)** — override globals and enter dedicated Cloudflare credentials for this site. Pick **API Token** or **Email & API key** as the authentication method.
       - **No (disabled for this site)** — never purge Cloudflare for this site, even if globally enabled.
