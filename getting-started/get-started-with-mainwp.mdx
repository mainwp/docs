MainWP requires two components:
- **MainWP Dashboard** - Install on a dedicated WordPress site that controls all other sites
- **MainWP Child** - Install on each WordPress site you want to manage

<Warning>
Install MainWP Dashboard on a clean WordPress installation rather than an operating site. This eliminates plugin conflicts.
</Warning>

MainWP Dashboard has no site limit. Check the [System Requirements](/advanced/miscellaneous/mainwp-system-requirements) to verify your server can handle your planned number of child sites.

## Prerequisites

Before starting, confirm you have:

- A dedicated WordPress site for the MainWP Dashboard (not an existing production site)
- PHP 8.3 or higher on the Dashboard server for MainWP Dashboard 6.4
- Administrator access to the Dashboard site
- Administrator access to each child site you want to manage
- MainWP Child plugin ready to install on child sites

## Manual Installation

<Steps>
<Step title="Download">
Download the [MainWP Dashboard](https://wordpress.org/plugins/mainwp) plugin.
</Step>
<Step title="Extract">
If downloaded as a zip, extract the plugin folder.
</Step>
<Step title="Upload via FTP">
Upload the plugin folder to `wp-content/plugins/` on your Dashboard site.
</Step>
<Step title="Activate">
Go to **WP Admin > Plugins** and activate MainWP Dashboard.
</Step>
</Steps>

The Quick Setup Wizard launches after a new MainWP Dashboard installation. Starting with MainWP Dashboard 6.4, the wizard is shorter. It focuses on connecting your first site and then shows that site's updates and monitoring status.

The wizard follows this sequence:

1. **Welcome** - Choose how to start
2. **Add Site** - Connect one site or import sites from a CSV file
3. **Site Summary** - Review updates and monitoring for your connected site

MainWP shows the **System Check** step only when a server requirement check fails. Client setup and guided tours are optional, and you open them from the Site Summary step.

To skip the wizard, click **Skip setup, I'll add sites later** on the Welcome step. You can start it again later from **top-right user menu > MainWP Tools** (`/wp-admin/admin.php?page=MainWPTools`) using **Start Quick Setup Wizard**.

### Welcome

The Welcome step asks **How do you want to start?** Choose one option:

- **Connect my first site** (recommended) - Add one WordPress site. MainWP checks the site and guides you through installing MainWP Child.
- **Import a CSV** - Upload a CSV file with each site's address and an administrator login.

### System Check

If your server fails a requirement needed to connect Child Sites, MainWP opens the System Check step before Add Site. [Resolve the issues](/troubleshooting/resolve-system-requirement-issues), then click **Next to Add Site**. If all checks pass, MainWP skips this step.

### Add Site

<Tabs>
<Tab title="Connect my first site">
1. Enter the **Site URL** and **Administrator username**.
2. Wait while MainWP checks the site. The checklist confirms **Site reachable** and **MainWP Child installed and active**.
3. If MainWP Child is missing or inactive, click **Open the site's Plugins page**, install and activate MainWP Child, then click **Check again**. MainWP keeps checking while the page is open.
4. Enter the **Administrator password**. Your Dashboard uses the password once to set up a secure key with the site. MainWP does not save the password or send it to MainWP.com.
5. Optional: Click **Advanced options** to choose the connection authentication method, enter a **Unique Security ID**, or set a site title.
6. Click **Connect site**.

<Note>
MainWP Child requires at least one connection authentication method: **Require Password Authentication**, **Require Unique Security ID**, or both. The authentication options in **Advanced options** must match the MainWP Child settings on the site: `your-child-site.com/wp-admin/options-general.php?page=mainwp_child_tab`
</Note>
</Tab>
<Tab title="Import a CSV">
1. Click **Upload the CSV file** and select your file. Download the sample CSV from the same field to see the expected format.
2. Click **Connect sites**.

MainWP uses each administrator password once to set up a secure key with its site. MainWP does not save the passwords or send them to MainWP.com.

To connect a single site instead, click **Connect one site instead**.

For details, see:
- [Connect Multiple Sites](/sites/management/manage-child-sites#connect-multiple-sites)
- [Import Sites (CSV)](/sites/management/manage-child-sites#import-sites-csv-import)
</Tab>
</Tabs>

Click **Skip for now** to go to the Site Summary without connecting a site.

### Site Summary

The Site Summary shows **Your first site is connected** with the site's details. When you import several sites, it shows the number of connected sites instead.

The summary includes these tiles:

| Tile | What it shows |
|------|---------------|
| **WordPress** | The site's WordPress version and whether an update is available |
| **Updates** | Waiting plugin, theme, translation, and WordPress updates. Shows **Awaiting first sync** until the first sync finishes. |
| **Uptime monitoring** | Whether uptime monitoring is on and who receives alert emails. Click **Turn off** to disable monitoring. |
| **Daily digest** | Appears when daily digest emails are enabled |

On a new installation, MainWP turns on uptime monitoring with a 60-minute check interval and enables Site Health monitoring with a threshold of 80. Change these defaults in [Uptime Monitoring](/sites/management/uptime-monitoring) and [MainWP Dashboard Settings](/sites/management/mainwp-dashboard-settings).

From the Site Summary, you can also:

- Click **Update everything now** to install all waiting updates on the connected site. MainWP asks you to confirm first. Make sure you have a recent backup.
- Click **Review updates first** or **View updates** to review updates before installing them.
- Click **Assign this site to a client** to open the Add Client step. Create a single client or, for imported sites, enter a client name and email for each site. Sites with matching client name and email are merged into one client profile.
- Click **Connect Claude or Cursor** to set up [MainWP MCP](/mcp-server/overview). This link appears for administrators when the REST API is available.
- Click **Add another site** to connect more sites.
- Select **Show me a guided tour of MainWP** to enable guided tours.

Click **Go to Dashboard** to finish setup.

## MainWP Child Plugin Settings

![MainWP Child plugin settings page](/images/getting-started/child-plugin-settings.png)

| Setting | Default | Description |
|---------|---------|-------------|
| Require Password Authentication | Enabled | Requires the administrator password when connecting from Dashboard. Can be disabled only when Unique Security ID is required |
| Unique Security ID | Disabled | Requires a matching Security ID when enabled. If Password Authentication is disabled, this must remain enabled |
| Connection Timeout | — | Minutes the plugin stays active waiting for connection |

MainWP Child requires at least one of **Require Password Authentication** or **Unique Security ID** to remain enabled.

For more details, see [Connection Security](/advanced/miscellaneous/mainwp-connection-security).

## Add a Site to Your Dashboard

After installing MainWP Child, add the site to your Dashboard.

<Steps>
<Step title="Navigate to Add New">
Log into your Dashboard and go to **MainWP > Sites > Add New**.
</Step>
<Step title="Enter site URL">
Enter your child site URL.
</Step>
<Step title="Verify Child plugin">
Toggle **Confirm the MainWP Child plugin is active on this site** to reveal additional fields.
</Step>
<Step title="Enter credentials">
Enter the administrator username and provide the authentication method required by MainWP Child settings:
- **Administrator password** - Required when **Require Password Authentication** is enabled
- **Unique Security ID** - Required when **Require Unique Security ID** is enabled

If both methods are enabled on the child site, provide both values.
</Step>
<Step title="Add optional settings">
| Option | Description |
|--------|-------------|
| Site icon | Upload custom icon or select built-in icon (favicon used if empty) |
| Tags | Organize site with existing or new tags |
| Client | Associate site with a client |
| Verify SSL certificate | Disable for self-signed or outdated certificates |
| HTTP username/password | For sites using HTTP Basic Authentication |
</Step>
<Step title="Connect">
Click **Add Site**.
</Step>
</Steps>

### Add-ons Settings Synchronization

When supported [MainWP Add-ons](https://mainwp.com/mainwp-add-ons/) are installed, the Add New Site form can show synchronization options:

- Install a required third-party plugin on the child site
- Apply the add-on plugin settings (or global add-on options) during site connection

<Note>
If you experience connection issues:
1. Use **Test Connection** to verify Dashboard can communicate with the site
2. Check [Potential Issues](/troubleshooting/potential-issues) for solutions
3. [Submit a support ticket](https://mainwp.com/mainwp-support/) if needed
</Note>

## Test Connection

Test Connection verifies what your MainWP Dashboard can reach, which may differ from what your browser sees.

<Steps>
<Step title="Open Add New">
Go to **MainWP > Sites > Add New**.
</Step>
<Step title="Enter URL">
Enter your child site URL.
</Step>
<Step title="Test">
Click **Test Connection**.
</Step>
</Steps>

![Test Connection button](/images/getting-started/setup-test-connection.png)

A successful test shows a modal with:

```
Connection successful!
URL: yoururl.com (IP: xxx.xxx.xxx.xxx) - Received HTTP-code 200 (OK)
```

For other results, see the [full list of HTTP Status Codes](/troubleshooting/connection-test-results-status-codes).

## Protect Your Connected Sites

After connecting your first Child Site, set up its backups. MainWP 6.4 includes [MainWP Built-In Backups](/sites/backups/manage-backups) (beta) for creating, scheduling, and restoring backups directly through MainWP Dashboard and MainWP Child. Start with a backup and restore test on a staging site.

You can also use [API Backups](/sites/backups/api-backups) with a supported hosting provider or an existing [backup add-on](/add-ons/backups).

## Completion Checklist

Verify your setup is complete:

- [ ] MainWP Dashboard installed and activated on dedicated site
- [ ] Quick Setup Wizard completed (or skipped intentionally)
- [ ] MainWP Child installed on at least one child site
- [ ] Child site connected successfully (shows in **MainWP > Sites > Manage Sites**)
- [ ] Test Connection returns HTTP 200 status
