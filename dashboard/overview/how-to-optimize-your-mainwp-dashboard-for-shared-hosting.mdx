---
title: How to optimize your MainWP Dashboard
description: >-
  Use Optimize data loading to search synchronized plugin, theme, and user data
  stored in the MainWP Dashboard database instead of querying Child Sites
  directly. This setting is enabled by default.
---

Optimize data loading is enabled by default. When enabled, plugin, theme, and user searches use synchronized data stored in the MainWP Dashboard database instead of querying selected Child Sites during each search.

If you make changes directly on a Child Site, synchronize that site before searching so the MainWP Dashboard uses the latest data.

To verify the setting:

<Steps>
<Step title="Go to MainWP > Settings > Advanced Settings">
</Step>
<Step title="Under Miscellaneous Settings, confirm Optimize data loading is enabled">
</Step>
<Step title="If you changed the setting, scroll down and click Save Settings">
</Step>
</Steps>
