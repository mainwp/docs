Add-on licensing issues typically occur when the connection between your Dashboard and MainWP's licensing server is interrupted. The solution usually involves deactivating and reactivating the add-on, then re-entering your API key.

## What You'll Learn

- Fix add-on license activation failures
- Resolve missing add-on updates
- Troubleshoot add-on update failures

## Prerequisites

- MainWP Dashboard with add-ons installed
- Valid MainWP API key(s) for your add-ons
- Admin access to your Dashboard site

---

## Add-on License Activation Fails

If your API key doesn't activate an add-on:

<Steps>
<Step title="Go to Plugins page">
Navigate to **WP Admin > Plugins**.
</Step>
<Step title="Find the add-on">
Locate the add-on that won't activate.
</Step>
<Step title="Deactivate the add-on">
Click **Deactivate** under the add-on.
</Step>
<Step title="Reactivate the add-on">
Click **Activate** to reactivate it.
</Step>
<Step title="Go to Add-ons page">
Navigate to **MainWP > Add-ons**.
</Step>
<Step title="Enter API key">
Try to activate your API key again.
</Step>
</Steps>

### If Activation Still Fails

| Issue | Solution |
|-------|----------|
| API key invalid | Verify the key in your [MainWP account](https://mainwp.com/my-account/) |
| Key already in use | Deactivate from the other site first |
| Connection timeout | Check firewall isn't blocking mainwp.com |
| Subscription expired | Renew your subscription |

## Add-on Updates Not Detected

Add-ons must be activated with your API key to receive automatic updates.

<Steps>
<Step title="Verify license activation">
Go to **MainWP > Add-ons** and confirm your add-ons show as activated.
</Step>
<Step title="If not activated, enter API key">
Enter your API key to activate the add-on.
</Step>
<Step title="If already activated, deactivate the add-on">
Go to **WP Admin > Plugins**, find the add-on, and click **Deactivate**.
</Step>
<Step title="Reactivate the add-on">
Click **Activate** to reactivate it.
</Step>
<Step title="Re-enter API key">
Go to **MainWP > Add-ons** and enter your API key again.
</Step>
<Step title="Check for updates">
Go back to **WP Admin > Plugins**, find the add-on, and click the **Check for Updates Now** link in the add-on description.
</Step>
</Steps>

## Add-on Update Fails

If an add-on shows an available update but won't install, reset the add-on activation and license connection before retrying the update:

<Steps>
<Step title="Go to Plugins page">
Navigate to **WP Admin > Plugins**.
</Step>
<Step title="Find the add-on">
Locate the add-on that won't update.
</Step>
<Step title="Deactivate the add-on">
Click **Deactivate** under the add-on.
</Step>
<Step title="Reactivate the add-on">
Click **Activate** to reactivate it.
</Step>
<Step title="Go to Add-ons page">
Navigate to **MainWP > Add-ons**.
</Step>
<Step title="Activate the license">
Activate the license for the add-on again.
</Step>
<Step title="Return to Plugins page">
Go back to **WP Admin > Plugins**.
</Step>
<Step title="Try updating again">
Attempt the update again.
</Step>
</Steps>

### If Update Still Fails

| Issue | Solution |
|-------|----------|
| License expired | Renew your subscription to receive updates |
| Server timeout | Increase PHP max_execution_time |
| Write permissions | Check wp-content/plugins folder permissions |
| Download failed | Verify mainwp.com is accessible from your server |

## Check Your License Status

You can verify your add-on licenses and subscription status:

1. Log in to [MainWP.com](https://mainwp.com/my-account/)
2. Go to **My Account > API Keys**
3. Check which API keys are active and where they're being used
4. Verify your subscription is active

## Self-Check Checklist

- [ ] Add-on is installed and activated as a plugin
- [ ] API key entered on MainWP > Add-ons page
- [ ] Add-on shows "Activated" status
- [ ] Updates detected after clicking "Check for Updates Now"
- [ ] Updates install successfully
