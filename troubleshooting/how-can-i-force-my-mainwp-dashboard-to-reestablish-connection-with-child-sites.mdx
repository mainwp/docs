title: Re-establish Connections with Child Sites
description: >-
  Use Re-establish Connections in MainWP Tools to reset the connection user's
  sessions on child sites. Learn when to reset signing keys separately.
---

Use **Re-establish Connections** in MainWP Tools when MainWP Support asks you to reset sessions for the administrator account used to connect child sites. The tool sends a signed request to each available child site to end that account's WordPress sessions.

To replace signing keys, use the separate **Reset OpenSSL Key Pair** tool.

## What You'll Learn

- When to use Re-establish Connections
- How to reset the connection user's sessions
- Which tool replaces signing key pairs

## Prerequisites

- MainWP Dashboard installed and activated
- Child sites previously connected to your Dashboard
- Admin access to your Dashboard

---

## When to Use Re-establish Connections

Use this tool only when MainWP Support recommends a session reset while troubleshooting a connection issue.

<Warning>
This ends all WordPress sessions for the MainWP connection user on each affected child site. Anyone signed in with that account must sign in again.
</Warning>

---

## Re-establish Connections

<Steps>
<Step title="Navigate to MainWP Tools">
Go to **top-right user menu > MainWP Tools** (`/wp-admin/admin.php?page=MainWPTools`).
</Step>
<Step title="Find the connection tool">
Locate the **Force your MainWP Dashboard to establish a new connection** option.
</Step>
<Step title="Click the button">
Click **Re-establish Connections** and confirm the action when prompted.
</Step>
<Step title="Wait for completion">
Wait for the progress window to finish and check for site-specific errors.
</Step>
<Step title="Verify connections">
Go to **MainWP > Sites > Manage Sites**, sync the affected sites, and confirm they respond successfully.
</Step>
</Steps>

---

## What the Tool Does

1. MainWP Dashboard sends signed session-reset requests to available child sites.
2. MainWP Child destroys all WordPress sessions for the current MainWP connection user.
3. Users signed in with that account must sign in again.

Existing signing key pairs remain in use. **Reset OpenSSL Key Pair** is the separate Tools action for generating replacement keys. See the [MainWP Tools reference](/sites/management/mainwp-dashboard-settings) for the available actions.
