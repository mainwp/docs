---
title: Export Sites
description: >-
  Export child site details to a CSV file for inventory, record-keeping, or use when moving sites to another MainWP Dashboard.
---

The Export Child Sites tool creates a CSV file containing the non-staging child sites available to your MainWP Dashboard user. The file includes site details, tags, connection settings, and any saved HTTP Basic Auth credentials. It does not include the OpenSSL keys for the active Dashboard-to-Child connection or stored administrator passwords.

## What You'll Accomplish

- Export your available non-staging child sites to a CSV file
- Create an offline inventory of site and connection settings
- Prepare an import file for moving sites to another MainWP Dashboard

## Prerequisites

- MainWP Dashboard installed and activated
- At least one non-staging child site available to your Dashboard user
- Permission to manage MainWP Dashboard settings

---

## Export Child Sites

<Steps>
<Step title="Open Tools">
Go to **MainWP > Settings > Tools**.
</Step>
<Step title="Locate export option">
Find the **Export child sites to CSV file** section.
</Step>
<Step title="Export">
Click **Export Child Sites**.

Your browser downloads `export-sites.csv`.
</Step>
</Steps>

---

## CSV File Contents

The exported CSV includes the following fields for each site:

| CSV header | Contents |
|-------|-------------|
| Site Name | Display name in MainWP Dashboard |
| URL | Full URL of the child site |
| Admin Name | Connected administrator username |
| Admin Password | Empty import-compatible column; MainWP Dashboard does not store the administrator password |
| Tag | Assigned tag names, separated by commas when a site has multiple tags |
| Security ID | Unique Security ID, if configured |
| HTTP Username | HTTP Basic Auth username, decrypted for the export |
| HTTP Password | HTTP Basic Auth password, decrypted for the export |
| Verify Certificate | Saved SSL certificate verification value |
| SSL Version | Saved SSL/TLS version preference |

<Note>
The current CSV import flow does not apply the exported SSL Version value when it adds a site. After importing, review the SSL Version for any site that uses a non-default value.
</Note>

## Common Use Cases

### Migrate to Another Dashboard

The CSV is a starting point for a transfer; it does not move the active connection keys.

1. Export sites from your current Dashboard.
2. Follow [Move Child Sites](/advanced/move-child-sites-to-another-mainwp-dashboard) to disconnect the sites from the current Dashboard and prepare them for the new connection.
3. Confirm that each CSV row contains the administrator password, Security ID, or both, as required by that site's MainWP Child connection settings. The exported Admin Password column is blank.
4. Import the CSV file in the new Dashboard at **MainWP > Sites > Add New > Import Sites**.

### Create a Backup Record

Export regularly to maintain an offline record of your site inventory. This file is not a backup of the active Dashboard-to-Child connection.

### Audit Your Network

Open the CSV in a spreadsheet application to review, sort, and filter your sites by tags, SSL status, or other attributes.

---

## Security Considerations

The exported CSV may contain sensitive information including:
- Administrator usernames
- Unique Security IDs
- HTTP Basic Auth usernames and passwords in plaintext

The file does not contain child site administrator passwords or the OpenSSL keys used for the active connection.

Store exported files securely and delete them when no longer needed.
